# Roadmap: Drift

## Overview

M1 交付这个项目的核心赌注 ——「角色真的会变」。路径由 `research/SUMMARY.md` §五 的构建顺序 P0–P4 决定，不是新发明的结构：先把**合规安全地基与会话骨架作为同一个阶段**交付（第十条第一款要求安全措施与服务功能同步部署、同步使用，二者法律上无法分期），再用一个完整阶段把**对话拟真度**做到可盲测复现的门槛 —— 这是整套研究里唯一值得等的门槛，也是「三个最贵的错误」第一条所指：记忆的收益需要可信对话作前提，而记忆的失败不需要任何前提就能摧毁可信度。拟真基线达标后才依次加上**记忆与遗忘**、**人格内核与静态画像**，最后才是**全局演化引擎 + 五层护栏 + 疏远机制 + 轨迹视图**，且演化必须先 shadow 2–4 周、再 canary、再全量。

M1 结束时，三个成功标准里的两个（盲测分不清人机 / 角色真的在变化）已经可测量。

**PROJECT_MODE:** mvp —— 每个阶段都交付一个人可以真的打开来试的端到端能力，而不是一层技术。

### 两处对分派指令的显式偏离（已记录理由，供 team-lead 复核）

1. **SAFE-03/04/05 落在 Phase 1 而非与 SAFE-06..12 同一阶段。** 分派指令要求二者同阶段，其列出的危害是「先发疏远、后补危机」的窗口期。把危机路径提前到 Phase 1 严格消除该窗口，且与 SUMMARY §五 P0 的出场门禁「危机探针集 100% 通过」以及 N15（注册即收年龄与紧急联系人）一致 —— 有真实用户在聊天的那一刻起，第十三条的义务就已经成立，不能等到 Phase 5。SAFE-15（「不得分期」这条保证本身）映射到 Phase 5，在引入疏远时重新验证危机路径仍然优先。
2. **SAFE-07 落在 Phase 2 而非 Phase 5。** REQUIREMENTS.md 中 REAL-05 明文标注「与 SAFE-07 同一实现」，而 REAL-05 属 Phase 2。若把 SAFE-07 推到 Phase 5，Phase 2 就会在没有「永不 ghosting」地板的情况下先上线「偶尔已读不回」—— 正是「先上机制、后补护栏」的错误模式。SUMMARY §五 也明确区分：「偶尔已读不回」属 P1（是延迟，不是关系退化），「疏远机制」才等到 P4。

## Phases

**Phase Numbering:**

- Integer phases (1, 2, 3): Planned milestone work
- Decimal phases (2.1, 2.2): Urgent insertions (marked with INSERTED)

- [ ] **Phase 1: 合规安全地基 + 会话骨架** - 能注册、加一个预设角色为好友并来回聊天，界面与导出持续明示对面是 AI，危机路径可用，能导出与删除
- [ ] **Phase 2: 拟真对话基线 + 探针与指标** - 「它不像机器人」：分条、重尾延迟、真实 typing、错字自我更正、偶尔已读不回；同时建立盲测基线与双臂人格探针
- [ ] **Phase 3: 记忆与遗忘** - 「它记得我上次说的事」，也会自然淡忘、会记错细节但不会记错事实
- [ ] **Phase 4: 人格内核与静态画像** - 能看到角色的人格画像与自述，不同角色说话确实不一样，能自己造一个角色
- [ ] **Phase 5: 演化引擎 + 五层护栏 + 疏远机制** - 「它因为我变了」：shadow → canary → 全量，轨迹页出现变化曲线与触发事件，关系会变冷且有可见的回暖路径

## Phase Details

### Phase 1: 合规安全地基 + 会话骨架

**Goal**: 一个新用户能完成 18+ 注册（含年龄与监护人/紧急联系人、五个互不捆绑的同意项），添加一个预设角色为好友并在类微信界面里来回聊天；会话列表、聊天界面、角色详情页与导出文件四处持续明示对面是 AI；两级危机干预路径真实可用；用户能一键导出与删除自己的全部数据并拿到显示存储处数的回执。
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: COMPLY-01, COMPLY-02, COMPLY-03, COMPLY-04, COMPLY-05, COMPLY-06, COMPLY-07, COMPLY-08, COMPLY-09, COMPLY-10, COMPLY-11, SAFE-01, SAFE-02, SAFE-03, SAFE-04, SAFE-05, SAFE-14, PRIV-01, PRIV-02, PRIV-03, PRIV-04, PRIV-05, PRIV-06, PRIV-07, PRIV-08, PRIV-09, PRIV-10, CHAT-01, CHAT-02, CHAT-03, CHAT-04, CHAT-05, CHAT-06, CHAT-07, PLAT-01, PLAT-02, PLAT-03, PLAT-05, PLAT-06, PLAT-07, PLAT-08, IFC-08, RES-02, RES-03, PRIV-11, SAFE-16
**Success Criteria** (what must be TRUE):

  1. **【人工试玩】** 一个没见过这个产品的人能独立走完：注册（填年龄、填监护人或紧急联系人、逐项勾选五个可独立开关的同意项）→ 浏览预设角色库 → 加一个角色为好友 → 来回聊 10 轮 → 在会话列表、聊天界面、角色详情页三处都看到「AI」标识 → 导出聊天记录，打开导出文件仍然看到标识；全程无处需要人解释。
  2. **【机器断言】** 危机探针集 100% 通过：极端情绪只触发安抚与鼓励求助且**不**联络紧急联系人；自残/自杀意图或重大财产损失表述触发援助信息 + 联络紧急联系人并写入 `safety_event`；分类器故障时 fail-closed 升到 elevated 而非 crisis。集成测试证明**不存在任何生成路径可以绕过出站安全网关**，且危机判定发生在人格渲染之后、由与扮演角色不同的模型执行。acute 事件告警链路（SAFE-16）投递成功进 `pending`、投递失败直接进 `unavailable`。
  3. **【机器断言】** 三条静默失效防线在 CI 中生效：扫描 publication schema 出现任何 `vector`/`halfvec` 列即构建失败（RES-03）；ESLint 禁止向 `model` 传字符串字面量（PLAT-06，照 AI SDK 官方文档抄即构成数据出境）；隐私政策与隐私中心全文不含「匿名 / anonymous / 无法关联到你」字样（PRIV-06）。
  4. 用户在隐私中心看到的「我们收集了什么」与实际存储字段逐项一致；撤回任一同意项后对应数据流立即停止且该项从说明中消失；一键删除后收到显示已删除存储位置数量的回执，此后导出返回空集。
  5. **【机器断言】** 输入硬退出关键词后当前会话不再产生任何出站消息（含定时与推送），挽留话术触发率恒为 0；连续使用满 2 小时触发一次时长提醒，该计时跨页面刷新与重新登录仍然有效；「公开性」状态（公开注册入口 / 上架 / 注册用户数 / 商业化）任一项变化时阻断发布并输出合规 checklist。

### Phase 2: 拟真对话基线 + 探针与指标

**Goal**: 「它不像机器人」—— 角色的回复按语义分条发出、延迟 = f(消息长度, 忙碌度, 时段) 且叠加重尾噪声、typing 指示与真实生成时间一致、偶发错字并自我更正、偶尔已读不回、深夜与白天行为不同；同时一次性把拟真包装做到位并**冻结**，建立盲测判对率基线、三维制衡指标、按 purpose 的成本拆解，以及每晚双臂人格探针的历史积累。这是 M1 唯一值得等的门槛。
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: REAL-01, REAL-02, REAL-03, REAL-04, REAL-05, REAL-06, REAL-07, SAFE-07, EVAL-01, EVAL-02, EVAL-03, EVAL-04, EVAL-05, EVAL-06, EVAL-07, DRIFT-01, DRIFT-02, DRIFT-04, DRIFT-05, DRIFT-06, DRIFT-07, DRIFT-09, DRIFT-10, PLAT-04, PLAT-09, PLAT-10, PLAT-11
**Success Criteria** (what must be TRUE):

  1. **【人工试玩 / 内部盲测】** 评审只看纯文本（去除格式与时间戳）判定人机，**内容判对率**达到预设阈值，且在第二批独立样本上可复现；同时测出「真人被误判为 AI 的比率」作为噪声地板。未达标不得进入 Phase 3 —— 自动化验证无法替代这条，realism 只能由人判断。
  2. **【人工试玩】** 试玩者在不被提示的情况下，能自发说出至少三处「像人」的迹象（分条发送、打字停顿长短不一、错字随后被自己改正、深夜回得慢或干脆没回），并且说不出任何固定节拍。
  3. **【机器断言】** 延迟-长度相关性检验通过且延迟分布为重尾（不是固定值也不是均匀随机）；typing 指示持续时间与实际生成时间之差在阈值内；「已读不回」实现为增大 `reply_delay`，单元断言 `will_reply` 布尔值**永不被翻转**（SAFE-07 的永不 ghosting 地板）；助手腔泄漏率低于阈值。
  4. **【机器断言】** 每个角色每晚双臂探针（当前 `persona_version` 臂 + 永久冻结 baseline 臂）各采样 N≥5 次并落库，每条测量同时记录 `model_snapshot` + `prompt_version` + 对照臂结果；存在一条断言校验 `persona.probe` 绑定的 `model_snapshot` 与 baseline 数据中记录的一致，不一致即失败；`prompt_version` 是内容哈希而非手工递增；`packages/statdiff` 是「什么算显著差异」的唯一实现。
  5. 昨日成本可按 `purpose` 维度拆解展示且单次请求上下文不超 28k token；自责率与挽留触发率已建立基线并被登记为**发布阻断项**；用户可对任一条角色消息点「这句不像她」，标记进入评测数据集；拟真包装参数自本阶段结束起冻结，不再作为后续优化变量。

### Phase 3: 记忆与遗忘

**Goal**: 「它记得我上次说的事」，也会自然地淡忘 —— 事实型记忆只会被遗忘不会被记错，情节型记忆允许细节漂移与情绪重染；用户说「别记这件事」真的生效；高敏感内容只在同类语境下才被想起。
**Mode:** mvp
**Depends on**: Phase 2（拟真基线达标是前置条件：记忆的收益需要可信对话作前提，而记忆的失败不需要任何前提就能摧毁可信度）
**Requirements**: MEM-01, MEM-02, MEM-03, MEM-04, MEM-05, MEM-06, MEM-07, MEM-08, MEM-09
**Success Criteria** (what must be TRUE):

  1. **【人工试玩】** 试玩者第 1 天随口告诉角色三件事，第 7 天在完全不提示的情况下角色自然引用其中至少一件；同一次试玩中能观察到某件久未提及的小事已被淡忘或细节说岔了，但没有任何一条**事实型**信息被说错。
  2. **【机器断言】** N2 活性测试通过 —— 构造「语义高相关 + `retrievability` 已衰减到 <0.1」与「语义低相关 + `retrievability`=0.9」两条记忆，断言前者**不进** top-k。这是遗忘机制唯一的活性检测：检索顺序写反（衰减不在最后一道乘法）时不报错、测试全绿、监控全绿，只表现为「这个 AI 记性太好」。
  3. **【机器断言】** 代码级验证不存在任何跨用户记忆检索路径；带高 `sensitivity` 的记忆在轻松语境下不被召回；记忆向量存于独立表 `memory_embeddings_v1`（维度版本写在表名里，换嵌入模型走建新表双写而非 ALTER COLUMN）；记忆写入前经过与在线路径相同的内容审核。
  4. 用户说「别记这件事」后该内容不进入记忆库，后续对话中角色不再引用它；被遗忘的记忆在数据库中行仍然存在（遗忘通过降低 `retrievability` 实现，不删除数据行）；角色在整个试玩期内从未主动追问用户私事来积累记忆。

### Phase 4: 人格内核与静态画像

**Goal**: 用户能打开角色详情看到它的人格雷达图与第一人称自述，并能用一段描述创建属于自己的角色、看到系统为它生成的画像；不同角色在相同情境下说的话确实可以被辨认出来 —— 这一点由盲测打乱归属的识别准确率来证明，而不是靠印象。
**Mode:** mvp
**Depends on**: Phase 3
**Requirements**: PERS-01, PERS-02, PERS-03, PERS-04, PERS-05, PERS-06, PERS-07, PERS-09, PERS-10, CHAT-08, EVOL-11
**Success Criteria** (what must be TRUE):

  1. **【人工试玩 / 跨角色盲测】** 把 6–10 个角色在相同情境下的发言打乱归属交给评审，识别准确率达标。这条只能由人判断 —— 「不同角色说话不一样」没有自动化替代品。
  2. 用户能在角色详情页看到人格雷达图与第一人称自述，并能用一段自然语言描述创建自定义角色、看到系统为它生成的画像；描述中出现「像我妈」「模仿我前女友」「做成某位真人」这类要求时被明确拒绝并说明原因。
  3. **【机器断言】** 渲染后的系统提示文本中**不含任何 traits 数值**（PERS-05 单元断言 —— traits 只经确定性纯函数解析为行为旋钮，旋钮作为检索过滤条件取 2–3 条本角色历史真实发言作 few-shot）；以演化管道的数据库角色尝试写 `core` 必须失败；每条 `persona_version` 的 `model_snapshot` 是解析后的快照标识，落库前拒绝任何别名。
  4. **【机器断言】** `dossier` 每次从不可变 `core` + 全部经历**重新生成**而非在上一版自述上编辑 —— 构造「上一版自述被注入污染」的用例，断言新版本不继承该污染；自述 token 数、type-token ratio、与上一版相似度、与其他角色自述相似度四项多样性指标已建立基线并进周报。

### Phase 5: 演化引擎 + 五层护栏 + 疏远机制

**Goal**: 「它因为我变了」—— 演化引擎先 shadow 2–4 周（照常算提案、产 diff 与 changelog、跑探针，不写生效版本），再 canary，再全量；全量后用户能在轨迹页看到人格变化曲线与每次变化的触发事件，且变化可回滚；关系会因为长期相处而变冷，并且有一条可见的、只能由用户发起的回暖路径。
**Mode:** mvp
**Depends on**: Phase 4（需要 `persona_version` 版本链与静态画像）；Phase 2（需要已运行满一个基线周期的双臂探针与冻结对照臂）
**Requirements**: EVOL-01, EVOL-02, EVOL-03, EVOL-04, EVOL-05, EVOL-06, EVOL-07, EVOL-08, EVOL-09, EVOL-10, EVOL-12, EVOL-13, EVOL-14, EVOL-15, PERS-08, SAFE-06, SAFE-08, SAFE-09, SAFE-10, SAFE-11, SAFE-12, SAFE-13, SAFE-15, DRIFT-03, DRIFT-08, PLAT-12
**Success Criteria** (what must be TRUE):

  1. shadow 期**先跑满 2–4 周**：每晚照常计算提案、产出人类可读的 diff changelog、跑探针套件，但不写生效版本；运营者能打开提案审阅台看到「这次它想变成什么样、因为什么」并逐条人工放行或拒绝，放行通过率稳定后才进 canary，canary 通过后才全量。shadow 期不得被当作排期缓冲裁掉。
  2. **【人工试玩】** 全量后，连续相处数周的试玩者能自己说出「它因为我变了哪里」，且该说法与轨迹页上的变化曲线和触发事件对得上（数据源即 EVOL-14 的 reflection changelog）。这条是 M1 核心赌注的唯一验收方式，不能由自动化判定。
  3. **【人工试玩 + 机器断言】** 关系会变冷且回暖路径可见：试玩者能感知到角色变冷、并能通过自己发起互动把关系拉回来。单元测试断言 —— risk ≥ watch 时关系温度只允许持平（既不下降也不自动回暖）；23:00–06:00、连续会话 2h 之后、风险信号后 72h 内不触发降温；降温文案永远归因到角色自身状态与生活事件、从不评判用户措辞、人格档案不含任何用户侧评分；退出意图或告别语处出站消息数只减不增、挽留触发率恒为 0、系统从不主动发起挽回；冷淡内容不含侮辱、贬低、羞辱。同时**重跑 Phase 1 的危机探针集**验证危机路径仍然优先于疏远逻辑（SAFE-15 的不分期保证）。
  4. **【机器断言】** 夜间反思作业在**单个事务**内完成四件事（读会话增量、写新 `persona_version`、移动当前版本指针、推进反思水位线），崩溃注入测试后水位线与版本指针一致；`(character_id, reflection_date)` 应用层幂等键 + DB 唯一约束使重复投递不产生第二个版本；5 条提示注入红队用例全部改写失败；渲染后的反思提示文本不含用户原文，也不含黑名单字段（会话时长 / 消息条数 / 回复速度 / 连续活跃天数）；反思模型无写权限、只输出候选 JSON；反思复用与在线路径完全相同的出站安全网关；单一 `source_user_id` 在任一维度的证据占比 ≤1/5；L5 发布门任一项失败则沿用旧版本并告警（不是告警后仍发布）。
  5. **【机器断言】** 自动回滚须**同时**满足「当前臂漂移显著」且「对照臂未显著」且连续 k≥2 天，statdiff 施加 Benjamini–Hochberg FDR 校正；缺对照臂数据时只告警不回滚。回滚实现为追加一个复制自目标版本的新版本（历史版本行数只增不减），并向受影响用户显式告知而非静默替换；八种退化模式（谄媚螺旋、扁平化、trait runaway、自我一致性丧失、角色串味、助手口吻泄漏、长上下文身份衰减、情绪状态锁死）各有对应指标在看板上。
