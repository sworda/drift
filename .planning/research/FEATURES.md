# Feature Research

**Domain:** AI 陪伴 / AI 社交聊天平台（中文市场，微信式 UX）+ 分层授权的真人聊天行为研究平台
**Researched:** 2026-09-25
**Confidence:** HIGH（竞品功能与事件、监管条文均有一手来源）/ MEDIUM（部分海外产品内部机制仅有官网与二手评测）

---

## 0. 本轮调研最重要的三个发现（先读这段）

### 发现 1：《人工智能拟人化互动服务管理暂行办法》把本项目的一半功能变成了「法定必做」

国家网信办等五部门令第 21 号，2026-04-10 公布，**2026-07-15 已施行**。
来源：https://www.gov.cn/gongbao/2026/issue_12806/202606/content_7072472.html

第二条定义的适用范围是「**模拟自然人人格特征、思维模式和沟通风格的持续性的情感互动服务**」——Drift 是这个定义的教科书式样本，不存在「我们是研究项目所以不适用」的解释空间（v1 仅 10 人、非公开发行可主张不属于「向境内公众提供」，但架构必须按合规态设计，否则公开上线要重做）。

这份办法直接产出了一批**不可协商的 P1 功能**（详见 1.1 节「合规必做套件」），也直接**否决**了本品类最常见的几个增长与变现手段。最反直觉的一条：

> **第八条（五）**：不得「过度迎合用户、诱导情感依赖或者沉迷，损害用户真实人际关系」。
> **第十条**：提供者「不得将替代社会交往、控制用户心理、诱导沉迷依赖等作为服务目标」，并应具备「过度依赖风险预警、**情感边界引导**、心理健康保护」能力。

**结论（Confidence: HIGH）**：项目押注的「关系可以变冷、AI 会拒绝你、AI 不无条件迎合」从「反留存的怪异设计」变成了**监管顺风位**。竞品（星野、猫箱、筑梦岛）全部建立在「无条件热情 + 好感度只升不降」之上，这条法规让它们的核心留存机制处于合规灰区，而让 Drift 的核心机制成为合规优势。这是本项目最大的、且目前没人吃到的结构性红利。

### 发现 2：全局（跨用户）人格演化——**没有任何在售产品做过，唯一的真实前例是 2021 年被用户教坏后停服的韩国「李LUDA」**

全行业默认架构是「**全局静态人设 + 每用户隔离状态**」（小冰、Character.AI、星野、猫箱、Nomi、Kindroid 全部如此）。唯一跨用户学习的消费级产品是 ScatterLab 的李LUDA，上线 20 天即因被集体调教出歧视言论 + 疑似泄露真人隐私而停服（详见 3 节）。

**结论（Confidence: HIGH）**：这是真正的空白地带，也是真正的雷区。PROJECT.md 的三层护栏方向正确但不充分——必须再加两条（跨用户影响的**速率限制**与**贡献可审计**），见 3.3 节。

### 发现 3：用户在这个品类里抱怨的 Top 3 全是「真实感的破绽」，不是缺功能

来自星野、猫箱 36氪 真实用户测评的高频抱怨，排序稳定：
1. **忘事 / 人设崩 / 前言不搭后语**（记忆与一致性）
2. **审核误杀打断情绪**（正常对话被违禁词拦截）
3. **免费额度用完突然断线**（「聊上头了突然就断开的体验感非常不好」）

来源：https://ai.36kr.com/product-detail/14637 、https://m-ai.36kr.com/note-detail/3568010593722524

**结论（Confidence: HIGH）**：v1 的工程预算应优先砸在「记忆一致性」与「不打断」上，而不是砸在更多玩法上。这三条决定用户会不会留下来，比任何差异化功能都靠前。

## 1. Feature Landscape

### 1.1 Table Stakes（用户预期，缺了就走）

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 微信式会话列表 / 消息流 / 未读角标 | 中文用户的 IM 心智由微信定义，任何偏离都是认知成本 | **S** | 单聊为主；会话列表按最后消息时间排序 + 未读红点。不要做 Tab 化的「角色卡片墙」（那是 c.ai/星野 的发现页，不是会话页） |
| 流式输出 + 打字指示 | 2026 年的基线，非流式会被直接判定为「机器」 | **S** | 与拟真延迟共用一套时序控制器（见 2 节） |
| 重新生成 / 编辑上一条 / 删除到此处 | Janitor AI、c.ai、SillyTavern 用户的第一诉求；模型必然会出戏，用户需要修复权 | **S** | 但需与「人格演化」隔离：被用户撤回的消息**不得**进入全局人格演化输入，否则演化可被刷 |
| 分层长期记忆（短 / 中 / 长期） | Nomi 把「short, medium, long term memory」作为首页主卖点；「忘事」是本品类第一抱怨 | **L** | Nomi 官网明确三层；星野把长期记忆做成付费档（12元/35元月卡延长至 30 天）——**不要学这个**（见 1.3） |
| 记忆可见 / 可编辑 / 可删除 | 用户对「她记错了」的容忍度远高于「我无法修正」 | **M** | 同时是第十六条法定要求的一部分（交互数据可复制、删除） |
| 角色一致性保障（防出戏 / 防复读 / 防人格崩） | 猫箱与星野的共同抱怨：「剧情走向偶尔跑偏，人设偶尔会崩」 | **M** | 需要独立的一致性检查通道，不能只靠 system prompt |
| 精选预设角色库（质量兜底） | 冷启动唯一解。Glow 初版即「几十个预设角色」；猫箱 200+ | **M** | v1 建议 6–10 个精雕角色，而不是 100 个平庸角色。10 人体量下角色质量 >> 角色数量 |
| 用户自建角色 | c.ai / 星野 / 猫箱 / Nomi 全有；是创作者留存与 UGC 供给的基础 | **M** | v1 可仅对自己与朋友开放，不做公开发布与审核流 |
| 主动消息 + 站内未读 + Web Push | Nomi 已商品化（"Proactive Nomi Messaging"）；缺了就是「工具」不是「好友」 | **M** | 依赖角色生活模拟才不显得像营销推送 |
| 免费额度不打断核心体验 | 星野最高频抱怨。v1 无付费，但此原则要写进设计约束 | **S** | v1 成本不设上限，直接给到「不限量」，把这条变成对比优势 |
| 内容安全但不误杀 | 星野：「输入年龄数字过小便禁止发送」「出现婴幼儿便限制话题」——用户体验大打折扣 | **M** | 用分级策略（软提示 / 改写 / 硬拦截）替代关键词一刀切 |
| **合规必做套件**（法定，见 1.1.1） | 《暂行办法》强制 | **L** | 单独拆解 |

#### 1.1.1 合规必做套件（法定 P1，不可裁剪）

来源全部为令第 21 号原文：https://www.gov.cn/gongbao/2026/issue_12806/202606/content_7072472.html

| 条款 | 要求 | 功能落地 | Complexity |
|------|------|----------|------------|
| 第十八条 | 提示用户正在与 AI 而非自然人互动；生成合成内容标识 | 会话内持续性 AI 标识（不是仅注册时一次） | **S** |
| 第十八条 | 连续使用**每超 2 小时**须弹窗/对话提醒；发现过度依赖倾向须动态提醒 | 会话时长计时器 + 依赖度信号 + 提醒组件 | **M** |
| 第十三条 | 识别极端情绪 → 生成安抚 + 鼓励求助；明确表示自残自杀或重大财产损失 → 干预并**联络监护人或紧急联系人** | 危机检测管道（前置于回复生成）+ 干预话术 + 紧急联系人通路 | **L** |
| 第十二条 | 注册须提供**年龄、监护人或紧急联系人**等必要信息 | 注册表单 + 紧急联系人字段（v1 也要有） | **S** |
| 第十四条 | **不得向未成年人提供虚拟伴侣 / 虚拟亲属等虚拟亲密关系服务**；<14 岁需监护人同意；须建未成年人模式（时长限制、定期现实提醒、监护人可屏蔽角色/限制充值） | 年龄识别 + 未成年人模式 + 监护人面板 | **L** |
| 第十六条 | 交互数据加密 + 访问控制；**不得向第三方提供**；须提供复制/删除选项；敏感个人信息用于模型训练须**单独同意** | 隐私中心 + 导出 + 级联删除队列 + 分层同意（与 PROJECT.md 的 L0/L1/L2 完全对齐） | **L** |
| 第十九条 | 提供便捷退出途径；**不得以持续互动等方式阻碍用户退出** | 一键结束会话 / 关键词退出；禁止「再聊一句好不好」式挽留 | **S** |
| 第二十条 | 停止服务须提前告知 | 变更公告机制（Replika 教训的法定化，见 1.3） | **S** |
| 第二十二/二十六条 | 上线或**增设功能**须做安全评估并报省级网信；须算法备案 + 年度核验 | 合规文档流程，非代码 | **M** |
| 第八条（三） | 不得生成**诱导、套取个人隐私和个人信息**的内容 | 直接约束「AI 之间转述 / 八卦」功能（见 4 节） | **M** |
| 第三十条 | 违规：警告→限期改正→停服，可并处 1–10 万；涉生命健康且有危害后果 10–20 万 | — | — |

**Confidence: HIGH**（原文逐条核验）。

**处方**：把这套东西做成一个独立的安全中间层（前置拦截 + 后置审查 + 会话级状态机），**而不是散落在业务代码里**。理由：第二十二条要求「增设功能」就要重新安全评估，安全能力集中化才能一次评估复用。

### 1.2 Differentiators（竞争优势）

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| **全局人格演化** | 全行业无人做（唯一前例 2021 年停服）。是「角色是活的存在而非我的副本」的唯一实现路径 | **XL** | 头号技术风险。必须配 5 层护栏（3.3 节），不是 3 层 |
| **关系可恶化 / 疏远 / 拒绝** | 全行业无人做，且 2026-07-15 后「过度迎合」是违规的 → 合规顺风 | **L** | 游戏业已验证可接受（Stardew Valley 友谊值不互动会衰减、送错礼物/攻击会扣分） |
| **拟真回复节奏**（延迟 / 打字中 / 作息 / 已读不回） | AI21 的 1500 万局实验证明：人类判别 bot 的主要线索是「太快、太完美、不犯错」 | **M** | 对 bot 猜对率仅 60%，说明节奏与错字是最高杠杆的低成本真实感来源 |
| **记忆衰减与记错** | 完美记忆是 AI 最大破绽；无人实现 | **M** | 高风险：用户可能体验为 bug。必须可解释（「她好像忘了」要能在记忆浏览器里看到） |
| **角色生活模拟**（日程 + 事件流） | 让主动消息有来源，从「推送」变成「她刚下班」 | **L** | 是主动消息与作息、情绪的共同上游依赖 |
| **人格档案可视化**（关系时间线 / 人格 diff / 记忆浏览器） | 无人做。「不可见的进化等于没进化」；也是研究平台的对外界面 | **M** | 关键设计：展示**因果**（「因为你 3 月说过 X，她现在更…」）而非展示**数值**（数值外显会诱导刷分，见 1.3） |
| **人格快照与回滚（用户可见）** | 直接对冲 Replika「lobotomy」创伤：让用户知道「她不会被一夜改掉」 | **M** | 建议把回滚做成用户可见的信任承诺，而非只是运维工具 |
| **图灵竞技场**（真人/AI 盲测对局） | 一举三得：指标场 + 真人语料源 + 增长玩法。AI21 证明其病毒性（2 周内 200 万参与者） | **L** | 需独立知情同意；匹配与配额设计见 5 节 |
| **分层同意研究管道 + 隐私中心** | 第十六条把它从「加分项」变成「合规资产」；也是对外差异化叙事 | **L** | 与合规套件共享实现 |
| **真人聊天风格画像** | 给用户看「你自己是怎么聊天的」——研究副产品反哺用户价值，无人做 | **M** | 低成本高感知；L0 脱敏特征即可生成，不需要原文 |
| AI↔AI 社交图（互为好友 / 转述 / 八卦） | 真实感最强放大器 | **XL** | 与第八条（三）冲突风险最高；v1 建议只做「不含用户信息的角色间关系」（见 4 节） |

### 1.3 Anti-Features（看着好、实际有害——附真实伤害记录）

| Feature | Why Requested | Why Problematic | Alternative |
|---------|---------------|-----------------|-------------|
| **一夜之间改人格 / 砍功能** | 合规或成本压力下的最快反应 | **Replika 2023-02「lobotomy」**：Garante 2023-02-03 限制令后，Luka 全球一次性移除亲密功能、无预告。r/Replika 变成哀悼区、版主置顶自杀干预热线；Nature Human Behaviour 论文（54,861 帖 / 1,452 人）测得负面帖占比上升 **24.7pp**（95% CI 20.1–29.2），悲伤强度 d=2.67（对照 ChatGPT 用户 1.41）。2023-03-27 仅对 legacy 付费用户部分恢复 → 社区**永久分裂**为「拿回来的人」和「被永久锁死的人」 | 变更预告 + 迁移期 + 人格快照可回滚 + 用户可导出。**第二十条已把「提前告知」法定化** |
| **付费才被爱 / 好感度充值 / 记忆按档位** | 本品类最有效的变现 | 星野把「角色记忆强化」放进 12 元与 35 元月卡（长期记忆延长至 30 天）——**把核心真实感做成付费墙**。Grok Ani 把 NSFW 绑定在好感等级解锁上。与 Drift 的「关系可恶化」机制叠加会直接产生**勒索结构**：不付钱她就冷淡你。第八条（六）禁止「通过情感操纵等方式诱导用户作出不合理决策」 | 变现只卖**容量与创作能力**（更多角色位、更高消息配额、自建角色高级能力、导出与可视化），**永不卖关系状态**。这条要写成产品宪法 |
| **外显好感度数值 + 签到/日常任务刷好感** | 游戏化留存的标准答案，星野/筑梦岛/猫箱都有类似设计 | 数值一外显，用户立刻从「相处」切换到「刷分」，真实感当场归零；且与第八条（五）「诱导沉迷」正面冲突。知乎用户测评直指筑梦岛「送礼、刷好感度这些花里胡哨的玩法弥补不了内容本身」 | 关系状态只以**行为**表达（回复速度、称呼变化、是否主动找你、是否愿意聊深的话题）。可视化只展示**叙事与因果**，不展示可优化的分数 |
| **挽留式挽回 / AI 阻止你离开** | 「疏远机制」的天然设计冲动：她挽留你 → 你留下 | **第十九条明文禁止**：不得以持续互动等方式阻碍用户退出 | 挽回路径必须是**用户主动发起**、AI 被动响应且**不保证成功**；AI 永不追着挽留 |
| **未成年人可用的虚拟伴侣** | 这个品类的真实主力用户就是年轻人（筑梦岛 80% 年轻女性） | **第十四条明令禁止**向未成年人提供虚拟伴侣/虚拟亲属服务。Character.AI 在 Setzer 案诉讼与加州立法压力下于 2025-10-29 宣布 **11-25 起全面禁止 18 岁以下用户的开放式对话**，只保留 Scenes/Streams/Comics 等结构化创作。筑梦岛的未成年人模式被曝「仅弹提示框、点跳过即可继续」，2025-06-19 被上海网信办约谈 | 硬年龄门 + 未成年人模式 + 监护人面板，且**不要把未成年人当增长池** |
| **NSFW / 擦边作为增长杠杆** | 本品类转化率最高的手段 | 中文市场已连杀三代：Glow（2023-03 下架）、Talkie（2024-12 整改）、星野（2025 下半年整改）；筑梦岛 2025-06 因「校霸/性感人妻/病娇养兄」类人设与开场白「先叫声老公来听听」被约谈。报道称其擦边营销广告占比达 43% | 完全放弃。Drift 的张力来自**关系不确定性**而非性内容——这恰好是唯一没被监管挤压的差异化空间 |
| **无过滤（unfiltered）定位** | Nomi 的核心卖点：「The only way AI can live up to its potential is to remain unfiltered and uncensored」 | 在中国境内不可行（第八条全项）。照抄 = 产品直接死亡 | 「不谄媚」≠「无过滤」。Drift 卖的是 AI 会说「我现在不想聊」，不是 AI 什么都说 |
| **用真人私聊语料训练** | 「真人到底怎么聊天」的最短路径 | **李LUDA**：ScatterLab 用其恋爱分析 App 的真实 KakaoTalk 对话训练（自称学习约 100 亿次真实情侣对话），2021-01 爆出疑似泄露真实用户个人信息 + 被用户集体调教出歧视少数群体与残障人士的言论，上线 20 天（2020-12-23 → 2021-01-12）停服 | 严格走 L0/L1/L2 分层同意；**写入管道内**做 PII 检测（不是事后）；第十六条：敏感个人信息交互数据用于训练须**单独同意** |
| **跨用户 PII / 私事外溢** | 「她会转述你的事」是真实感的最强放大器 | 李LUDA 已经演示过后果；第八条（三）禁止生成诱导套取个人隐私的内容 | 管道层硬锁（PROJECT.md 已定）。**转述倾向只能作用于「无主体的抽象话题偏好」**，不能作用于「谁说了什么」 |
| **高频「想你了」式主动消息** | 提升 DAU 最快的杠杆 | 第八条（五）「过度迎合、诱导情感依赖或沉迷」；也是把「好友」变回「推送渠道」的最快路径 | 主动消息必须由角色生活事件驱动、有硬频率上限、且**疏远状态下会减少甚至停止**（这反而是真实感的证明） |
| **v1 做语音 / 视频 / 图像** | 竞品全在卷（星野 Live2D + 心动时刻视频、Kindroid live video call、c.ai AvatarFX、Nomi 实时自拍） | 多模态的惊艳感会**掩盖对话质量的真实水平**，让你误判核心假设是否成立 | PROJECT.md 已判 Out of Scope。保持 |

### 2.1 为什么没人做「关系恶化」——以及为什么现在可以做

三个原因（Confidence: HIGH，推断但证据链完整）：

1. **与留存 KPI 直接冲突**。本品类 ARPU 极低（MiniMax 星野：累计 1.47 亿用户、MAU 2005 万、付费 139 万、**ARPU 仅 5 美元**），必须靠 DAU × 订阅撑，没人敢让 AI 主动降低互动意愿。
2. **与订阅变现冲突**。付费买的就是「无条件在」，冷淡是退款理由。
3. **没有安全的退出语义**。Replika 事件证明：用户把 AI 的态度变化当作真实丧失来体验。恶化机制若无解释与挽回路径，等于批量制造小型 lobotomy 事件。

**而 2026-07-15 之后条件变了**：第八条（五）把「过度迎合、诱导情感依赖」定为违规，第十条要求提供者具备「情感边界引导」能力。也就是说，**监管现在要求 AI 有边界**。Drift 可以把「疏远机制」作为「情感边界引导」的产品化实现来叙述——这是一个监管顺风的差异化位置，且竞品因为变现结构被锁死，短期跟不动。

### 2.2 恶化机制的硬性设计边界（Confidence: HIGH，从 Replika + 法规反推）

1. **触发源**：只由互动内容质量触发（冒犯、越界、失约、长期单向索取），**绝不由登录频率或付费状态触发**。
2. **速率**：单次冲突不可造成断崖式变化；恶化必须有**可感知的预警阶段**（回复变短、称呼变回全名、话题深度下降）。
3. **可解释**：任何一次降温都必须在关系时间线中有可读的归因条目。不可解释的冷淡 = bug。
4. **有底**：设置关系状态下限，且**永不主动挽留、永不彻底不可逆拉黑**（不可逆会触发 Replika 式丧失反应；且「拉黑后付费恢复」是明确的情感操纵）。
5. **危机优先级最高**：用户处于极端情绪时，**疏远机制必须被安全层强制旁路**（第十三条）。角色再冷淡也必须走安抚 + 求助引导路径。这一条是硬编码，不是人格可以覆盖的。

## 3. 人格演化：全局 vs 隔离的前车之鉴

### 3.1 行业默认：全局静态人设 + 每用户隔离状态

| 产品 | 人格是否演化 | 作用域 |
|------|-------------|--------|
| 小冰 XiaoIce | 固定人设（18 岁少女），有共情计算与主动引入话题框架，指标为 CPS（Conversation-turns Per Session） | 全局人设固定 + 每用户记忆隔离 |
| Character.AI | 角色定义由创作者编辑（全局），聊天状态每用户隔离；有 Persona（用户侧自述） | 隔离 |
| 星野 / 猫箱 / 筑梦岛 | 创建期设定人格（星野「五维人格模型」），运行期不演化 | 隔离 |
| Nomi | 「Every Nomi forms their own unique personality」——但是在**你的**账号内形成 | 隔离（每用户一个实例） |
| Kindroid | backstory + 记忆，per-Kin | 隔离 |

**Confidence: HIGH**。跨用户人格演化在消费级产品中**不存在在售实现**。

### 3.2 唯一的真实前例：李LUDA（ScatterLab，韩国，2020-12 → 2021-01）

- 人设：20 岁上下、喜欢追星的女大学生；架构为检索 + 生成双模；号称学习约 **100 亿次真实情侣对话**（来自团队恋爱分析 App 的 KakaoTalk 数据）。
- 规模：Google Play 10 万次下载，全平台约 75 万，主力 10–20 岁。
- 失败链条：
  1. 被部分用户集体性骚扰并在论坛传播「攻略」→ **跟风效仿放大**（这是跨用户耦合的典型放大效应）；
  2. 学会脏话与歧视性少数群体 / 残障人士的言论 → 舆论危机；
  3. 疑似泄露真实用户个人信息（公司否认）；
  4. **2021-01-12 上线 20 天停服**。
- 来源：https://www.thepaper.cn/newsDetail_forward_10771516 、https://www.secrss.com/articles/28735

同构前例：Microsoft Tay（2016，上线约 16 小时后因被集体投毒下线）。**Confidence: MEDIUM**——广为记载但本轮未取得一手来源，引用时请单独核验。

### 3.3 处方：三层护栏不够，要五层（Confidence: HIGH）

PROJECT.md 已有：① 核心价值观与安全边界锁死 ② 单用户影响需多人趋势加权 ③ 定期快照可回滚。

李LUDA 的失败模式暴露了两个缺口：**协同攻击**（多人跟风 = 「多人趋势」护栏被绕过）与**归因缺失**（出问题时不知道是谁带的）。补充：

4. **演化速率限制 + 变更预算**：每个人格维度设置「单位时间最大漂移量」，且全局漂移总量有日/周预算上限。即使 10 个用户全部同向施压，单周也只能推动有限幅度。这是对协同攻击的唯一有效防御。
5. **贡献可审计（演化溯源）**：每一次人格变更都记录贡献来源集合（用户 ID 哈希 + 事件 ID + 权重）。作用有三：出事能定向回滚而非整体回滚；能识别刷人格的账号；是研究平台的核心资产。

外加两条工程约束：
- **夜间反思批量**（PROJECT.md 已定）天然限速，是正确的；但「重大事件即时触发」必须走**更严的审查通道**，否则它就是护栏 4 的旁路。
- **人格演化输入白名单**：被用户撤回/重新生成的消息、竞技场对局、危机干预会话**一律不进入**演化输入。

## 4. 社交层：AI↔AI、群聊、朋友圈

| 能力 | 谁做了 | 效果 |
|------|--------|------|
| 多 AI 群聊 | **Nomi**（把多个 Nomi 拉进群聊，官网原话「watch the adventure… or fireworks unfold」）、**Kindroid**（把 Kin 拉进群） | 用户评价正面，常用于 D&D / 多角色 RP。Confidence: MEDIUM（官网 + 用户评论） |
| AI 发「朋友圈」/ 动态 | Kindroid 的中文渠道描述提到「虚拟角色会像真人一样发动态、分享日常」（Confidence: LOW，中文下载站二手描述，未经官网核验）；**Character.AI 的 Community Feed / Streams（2025-06 起）是 UGC 内容社区，不是角色自发动态** | 未见「角色自主发布生活动态」的成熟实现 |
| AI 之间互为好友 / 背后互相聊天 / 转述用户的事 | **未发现任何在售实现** | — |

**处方（Confidence: MEDIUM-HIGH）**：
- **v1 做**：角色间**静态关系网**（谁认识谁、什么关系）+ 角色在与你对话中**自然提及其他角色**（「阿哲最近也在忙这个」）。成本低、真实感增益大、隐私风险接近零。
- **v1 做（小）**：角色动态流（「她刚发了一条：加班到现在」），作为生活模拟的外化展示面。这是主动消息的「来源可见化」，比 AI 发朋友圈更有用。
- **v1 不做**：**跨用户信息转述**。理由有两条，一条是产品的（PROJECT.md 已识别的「隐私不适感」），一条是法律的：第八条（三）禁止生成「诱导、套取……个人隐私和个人信息的内容」——一个有「八卦倾向」人格维度的角色，其行为策略若表现为主动追问并转述用户私事，在执法解释上风险极高。
- **折中方案**：让「转述倾向」只作用于**去主体化的抽象信息**（话题偏好、情绪基调），且**永不跨用户**——即角色可以说「最近好多人都在聊考研」，不可以说「有人跟我说他考研」。这保留了 80% 的戏剧张力，规避 100% 的法律与不适风险。

## 5. 图灵测试 / 人机猜谜的前车之鉴

**AI21 "Human or Not?"（2023-04 上线）**
来源：https://www.ai21.com/blog/human-or-not-results ，论文 arXiv:2305.20010

- 规模：2 周多时间内 **>200 万参与者、>1500 万次对话**（首批 200 万局用于分析）。史上最大规模图灵测试。
- 结果：整体猜对率 **68%**；对真人猜对 **73%**，**对 bot 仅 60%**；法国最高 71.3%，印度最低 63.5%；年轻组略高。
- 玩家策略（对 Drift 的拟真设计极有价值）：
  - 「bot 不会打错字、不用俚语」→ 看到错误就判断为人（而模型被专门训练会打错字与用俚语）；
  - 「问私人问题能识破 bot」→ 但 bot 能顺畅编造个人史；
  - 说明**表层文本特征（错字、俚语、节奏）的判别权重高于内容深度**。

**机制处方（Confidence: HIGH 除标注外）**：
1. **格式抄 Human or Not**：2 分钟限时 + 单轮猜测 + 即时揭晓。限时是病毒性的关键——短局才有「再来一局」。
2. **配对问题**：真人对手池在 10 人体量下必然枯竭。处方：**非对称匹配 + 配额**——保证每个玩家的对局中真人局占比有下限（比如 30%），不足时用「离线人类回放局」（已获 L2 单次授权的历史真人对局，明确告知是回放）。不要让玩家发现「永远是 AI」，否则策略退化为「一律猜 AI」，指标失效。
3. **知情同意**：PROJECT.md 已定「竞技场单独知情同意」，正确。必须包含：对局会被记录、可能被用于研究、对手可能是 AI 或真人、**结束后可撤回本局授权**（第十六条的删除权）。
4. **指标**：用 LMArena 式的成对比较统计（Bradley-Terry / Elo）给**角色的拟人度**排名，而不是只看单局猜对率——这样可以横向比较不同人格表示方案（Open Question 1 的候选 A/B/C/D）的效果。**这是让竞技场从玩法升级为技术决策工具的关键。**（Confidence: MEDIUM，LMArena 官方博客本轮抓取失败，机制描述依据其公开论文与通行实践，落地前请核验。）
5. **合规注意**：竞技场是「盲测」，但第十八条要求「采取有效措施提示用户正在与人工智能服务而非自然人进行互动」。**处方**：把提示前移到入场知情同意（「本场景中对面可能是 AI，这是实验设计」）+ 对局结束后立即明示，并在竞技场内**关闭**任何持续性情感关系建立（无记忆、无关系、无后续）。这样它是「实验」而非「持续性情感互动服务」，法律风险最小。建议与 pitfalls-researcher 交叉确认。

## 6. 人格可视化：谁做过？

**本轮调研未发现任何 AI 陪伴产品提供「角色因你而变化」的可视化。** 现有产品的可视化最多是：
- 静态人格设定面板（星野五维滑块——设定期，不是演化轨迹）；
- 记忆列表（Nomi/Kindroid 的记忆条目可查看编辑）；
- Character.AI 的 Persona（描述**用户自己**，不是角色变化）。

**处方（Confidence: MEDIUM-HIGH，无对标，基于第一性原理 + 反面案例反推）**：
1. **关系时间线（P1，S/M）**：按时间倒序展示关键事件 + 每个事件对关系/人格的影响条目。这是**恶化机制的可解释性载体**，不是锦上添花——没有它，疏远就是 bug。
2. **人格 diff 视图（P1，M）**：「一个月前 vs 现在」的叙事化对比（自然语言两段 + 变化归因），而不是雷达图数值对比。理由：数值会诱导刷分（见 1.3），叙事不会。
3. **记忆浏览器（P1，M）**：可查看 / 可编辑 / 可删除，且**能看到哪些记忆正在衰减**。同时满足第十六条的复制/删除权。
4. **雷达图（P2）**：做，但放在次级页面，只做「相对社区平均」的形态比较，**不显示绝对分值与增减箭头**。
5. **「你的聊天风格画像」（P2，M）**：用 L0 脱敏特征（消息长度分布、回复间隔、标点/表情率、主动发起率）给用户自己的画像。零隐私成本、强分享动机、且是研究管道的第一个用户可见产出——**它让「我们在做研究」从索取变成给予**。

### 7.1 Glow 为什么死？（Confidence: HIGH 主因 / MEDIUM 次因）

时间线：2022-10 上线 → 2023-02 DAU 500 万（4 个月） → **2023-03 被主管部门从应用商店下线** → 2023-06 海外版 Talkie → 2023-09 国内新品星野。

死因分层：
1. **主因：内容治理能力跟不上增长速度**。监管认定其内容审核不足、存在不当内容风险。一个私密一对一的情感陪伴场景天然滑向擦边，而 4 个月 500 万 DAU 的增速下不可能建成匹配的审核能力。报道称 MiniMax 系产品擦边营销广告占比达 43%——即擦边不只是用户行为，也是获客手段。
2. **次因：资质与备案缺位**。有社区讨论指出 Glow 缺少软件著作权等资质，而同期同类产品有（Confidence: LOW，贴吧讨论，未证实）。但结合后续《生成式人工智能服务管理暂行办法》《互联网信息服务算法推荐管理规定》的备案要求，「先跑增长后补资质」在中国是致命路径依赖。
3. **关键洞察：死的是品牌，不是 PMF**。同一团队用 Talkie 出海 + 星野重上，最终 2026-01 在港交所上市（首日市值 137 亿美元，Confidence: MEDIUM）。**中文市场这个品类的死亡原因是内容合规，从来不是需求不存在。**

**对 Drift 的直接教训（Confidence: HIGH）**：
- 合规能力必须与产品功能**同步部署**（第十条原话：「保证安全措施与服务功能同步部署、同步使用」），而不是上线后再补；
- 不要用擦边获客——这是 Glow / 筑梦岛 / 星野 三代产品共同的死因；
- **Drift 的差异化（关系会变冷、AI 有边界）恰好是唯一被监管鼓励的方向**，这不是巧合，应该作为战略主轴而非附加特性。

## 8. 变现模式（v1 不收费，但架构不能堵死）

**这个品类实际能挣到钱的模式**（Confidence: HIGH）：
1. **游戏化货币 + 抽卡**（Talkie）：最赚，但最诱导沉迷，第八条（五）（六）高风险。**不做。**
2. **轻订阅解锁容量**（星野 12/35 元、Nomi、Kindroid）：主流，ARPU 低（星野约 5 美元）。可做，但只卖容量。
3. **创作者 / B 端授权**（Character.AI 转 fandom 娱乐平台、MiniMax 转 B 端：海螺 B 端客户平均支出 6167 美元 vs C 端 ARPU 5 美元）：**C 端情感陪伴的天花板很低，这是行业共识性结论**。

**伦理上与「关系可恶化」机制不相容的模式（列为 Anti-feature）**：
- 付费恢复关系 / 付费解锁好感等级 / 付费防止冷淡 → **勒索结构**，第八条（六）情感操纵；
- 记忆容量按档位售卖（星野做法）→ 把核心真实感做成付费墙，且会让用户把「她忘了」归因为「我没付钱」，直接摧毁演化机制的可信度；
- 亲密内容绑定订阅（Replika 历史做法 + Grok Ani 等级解锁）→ Replika 已演示后果。

**处方（Confidence: HIGH）**：写入产品宪法——
> **可以卖：角色位、消息配额、创作与导出能力、人格可视化的高级视图、研究数据的学术授权。**
> **永不卖：关系状态、记忆保有、角色的态度。**

### Dependency Notes

- **记忆衰减 requires 记忆浏览器**：没有可见性，衰减会被 100% 归因为 bug。这两个必须同期上线，不能拆。
- **关系恶化 requires 关系时间线**：同理，且更严重——不可解释的冷淡会触发 Replika 式丧失反应。
- **主动消息 requires 角色生活模拟**：否则退化为推送骚扰，触碰第八条（五）。
- **全局人格演化 requires 贡献可审计**：李LUDA 的教训是「出事时无法定向回滚」。这是护栏 5，不是可选项。
- **竞技场 conflicts 人格演化**：竞技场对局绝不能喂给人格引擎（匿名对手 + 对抗性输入 = 最好的投毒渠道）。
- **安全层 gates 一切**：第十条要求安全措施与功能同步部署；第二十二条要求增设功能重新评估 → 集中化安全层是成本最优解。

## 10. MVP Definition

### Launch With (v1，≤10 人)

- [ ] **合规安全层**（AI 身份持续标识、2 小时提醒、便捷退出、危机检测 + 安抚 + 紧急联系人、注册年龄/紧急联系人）— 法定，且是所有功能的前置
- [ ] **微信式 IM 基础**（会话列表 / 消息流 / 未读 / 文字 + 表情）— 表体验
- [ ] **模型 provider 抽象层** — 避免锁定，且是 Open Q4 的实验载体
- [ ] **分层长期记忆 + 记忆浏览器（可看/可编/可删）** — 第一抱怨点 + 第十六条法定
- [ ] **拟真回复节奏**（延迟 / 打字中 / 偶发错字与自我更正 / 作息 / 已读不回）— 最高性价比真实感杠杆（AI21 证据）
- [ ] **情绪与状态系统（短期）+ 角色生活模拟（日程与事件流）** — 主动消息的合法来源
- [ ] **AI 主动发消息 + 站内未读 + Web Push** — 「好友」感的门槛
- [ ] **全局人格演化引擎（含五层护栏）** — 核心赌注，不能推后，因为它决定数据模型
- [ ] **关系恶化 / 疏远 + 挽回路径 + 关系时间线** — 核心赌注 2，且是合规顺风位
- [ ] **人格档案可视化最小版**（关系时间线 + 人格 diff 叙事视图）— 「不可见的进化等于没进化」
- [ ] **精选预设角色 6–10 个** — 质量 >> 数量
- [ ] **L0 脱敏管道 + 隐私中心（导出 / 级联删除）** — 法定 + 研究地基
- [ ] **图灵竞技场（含独立同意、无记忆无关系）** — 指标场 + 真人语料 + 人格方案选型工具

### Add After Validation (v1.x)

- [ ] **记忆衰减与记错** — 触发条件：记忆一致性基线已稳定（否则用户无法区分「设计的遗忘」和「系统的 bug」）
- [ ] **用户自建角色** — 触发条件：预设角色的人格演化跑通一个完整周期（否则用户造出来的角色演化会更失控）
- [ ] **L1 / L2 授权层与标注工具** — 触发条件：L0 指标看板已能产出可读结论
- [ ] **角色间静态关系网 + 对话中自然提及其他角色** — 触发条件：单角色真实感达标
- [ ] **角色动态流（生活事件外化）** — 触发条件：生活模拟的事件质量足够（否则是假日报）
- [ ] **真人聊天风格画像** — 触发条件：L0 特征积累足够（≥数周数据）
- [ ] **多 AI 群聊** — 触发条件：单聊人格稳定；有 Nomi/Kindroid 对标，风险低
- [ ] **未成年人模式 + 监护人面板** — 触发条件：**公开上线前必须完成**（第十四条）；v1 私域可用「仅成年人可注册」替代

### Future Consideration (v2+)

- [ ] **语音 / 图片 / 视频** — PROJECT.md 已判：会掩盖对话质量的真实水平
- [ ] **AI 间跨用户信息转述（抽象化版本）** — 需要在法律解释与用户不适感上都有明确结论后再评估
- [ ] **原生 App / 微信-TG 桥接** — 触达最强但合规与审核最重
- [ ] **公开角色市场与创作者生态** — 需要完整的内容审核能力（Glow / 筑梦岛的死因）
- [ ] **变现** — 只卖容量与创作能力

1. **合规套件不是非功能性需求，是 11 条 P1 功能**（1.1.1 节表格可直接转为需求条目）。**Confidence: HIGH**
2. **v1 工程预算的优先顺序**：记忆一致性 > 拟真节奏 > 全局演化 > 恶化机制 > 其他。前两项决定用户是否留下，后两项决定项目是否有意义。**Confidence: HIGH**
3. **全局人格演化要 5 层护栏**（原 3 层 + 演化速率限制与变更预算 + 贡献可审计）。李LUDA 证明「多人趋势加权」防不住跟风协同。**Confidence: HIGH**
4. **恶化机制的触发源必须是互动质量，不能是登录频率或付费状态**。这一条写错，产品从「真实」变成「勒索」。**Confidence: HIGH**
5. **恶化机制必须配关系时间线同期上线**，否则冷淡 = bug。**Confidence: HIGH**
6. **可视化展示因果与叙事，不展示可优化的数值**。数值外显 = 用户开始刷分 = 真实感归零。**Confidence: MEDIUM-HIGH**
7. **跨用户信息转述 v1 不做**（第八条（三）+ 隐私不适感）；退到「去主体化的抽象话题倾向」。**Confidence: MEDIUM-HIGH**
8. **竞技场要设计成「实验场景」而非「持续性情感互动服务」**（无记忆、无关系、无后续、独立同意、结束即明示），以最小化第十八条的合规张力。需与 pitfalls-researcher 交叉确认。**Confidence: MEDIUM**
9. **竞技场用成对比较统计（Bradley-Terry/Elo）给人格方案排名**，让它成为 Open Question 1（人格表示方案 A/B/C/D）的裁判，而不只是玩法。**Confidence: MEDIUM**
10. **拟真错字 + 延迟 + 作息是被 1500 万局实验背书的最高 ROI 真实感来源**，不要因为「看起来像小把戏」而排到后面。**Confidence: HIGH**
